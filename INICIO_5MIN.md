# ⚡ Início em 5 Minutos - V24

## Para quem tem pressa! 🚀

### 1️⃣ Extrair (30 segundos)
```
Descompacte site_coral_v24_FINAL.zip
```

### 2️⃣ Renomear (10 segundos)
```
index_v24.html → index.html
```

### 3️⃣ Configurar Sheet (2 minutos)
Abra `scripts/scripts.js` e encontre esta linha (aprox. linha 200-300):

```javascript
const SHEET_CSV_URL = 'COLE_SUA_URL_AQUI';
```

**Como obter a URL:**
1. Abra seu Google Sheets
2. Arquivo → Publicar na Web
3. Escolha a aba do catálogo
4. Formato: CSV
5. Copie o link
6. Cole no lugar de `COLE_SUA_URL_AQUI`

### 4️⃣ Testar (1 minuto)
```
Abra index.html num navegador
Clique em "Atualizar catálogo"
Se aparecerem cânticos = ✅ Funcionou!
```

### 5️⃣ Usar Sugestões (1 minuto)
```
1. Vá para aba "Programa"
2. Escolha uma data
3. Vá para aba "Sugestões"
4. Clique "Usar" nas sugestões que gostar
5. Pronto! 🎉
```

## 🚨 Problemas Instantâneos

### "Não carrega cânticos"
→ URL do Google Sheets errada  
→ Sheet não publicada  

### "Sugestões não aparecem"
→ Escolha uma data primeiro  
→ Catálogo precisa estar carregado  

### "Tudo em branco"
→ Caminho do scripts.js errado  
→ Verifique estrutura de pastas
