# 📥 Exportação de Programas - DOCX e PDF

## ✨ Nova Funcionalidade

Agora pode exportar programas em **3 formatos diferentes**:

1. **📄 Imprimir (navegador)** - Impressão direta do browser
2. **📥 Exportar DOCX** - Documento Word com margens perfeitas ⭐
3. **📥 Exportar PDF** - PDF com margens controladas ⭐

---

## 🎯 Vantagens dos Novos Formatos

### Problema da Impressão do Navegador:
- ❌ Margens impostas pelo navegador/impressora
- ❌ Difícil controlar resultado final
- ❌ Varia entre impressoras

### Solução: Exportar DOCX ou PDF:
- ✅ **Margens exatas:** 2cm topo, 2cm esquerda, 1cm direita, 1cm rodapé
- ✅ **Sempre iguais:** independente da impressora
- ✅ **Editável (DOCX):** pode personalizar antes de imprimir
- ✅ **Partilhável:** envia por email, guarda no Drive, etc

## 📥 Exportar DOCX (Word)

### Como Usar:

1. **Preencher programa** na aba "Programa"
   - Data
   - Título litúrgico
   - Todos os cânticos

2. **Clicar "📥 Exportar DOCX"**

3. **Ficheiro é descarregado** automaticamente
   - Nome: `Programa_2024-11-26_i-domingo-do-advento.docx`

4. **Abrir no Word, LibreOffice ou Google Docs**

5. **Imprimir ou editar conforme necessário**

### Formato do DOCX:

```
┌─────────────────────────────────────────────────────────┐
│           Coro Paroquial São João Batista               │ ← 2cm topo
│              de Rio Caldo                               │
│                                                         │
│        I Domingo do Advento — Ano B                     │
│           Data: 26/11/2024                              │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
2cm  🎉 Entrada                                       1cm
│    Vinde, Cantai ao Senhor                             │
│    Autor: João Silva                                   │
│                                                         │
│    [letra do cântico]                                  │
│    linha 1                                             │
│    linha 2                                             │
│    ...                                                 │
│                                                         │
│    _________________________________________           │
│                                                         │
│    🙏 Ato Penitencial                                  │
│    Perdão, Senhor                                      │
│    ...                                                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
                      ↑ 1cm rodapé
```

### Características:
- ✅ Margens: 2cm | 1cm | 1cm | 2cm
- ✅ Fonte: Calibri/Arial (padrão Word)
- ✅ Cabeçalho centralizado e formatado
- ✅ Cada parte com ícone emoji
- ✅ Títulos em negrito
- ✅ Autores em itálico
- ✅ Letras formatadas
- ✅ Separadores entre partes
- ✅ Totalmente editável!

## 📥 Exportar PDF

### Como Usar:

1. **Preencher programa** na aba "Programa"

2. **Clicar "📥 Exportar PDF"**

3. **Ficheiro PDF é descarregado**
   - Nome: `Programa_2024-11-26_i-domingo-do-advento.pdf`

4. **Abrir e imprimir diretamente**

### Formato do PDF:

Idêntico ao DOCX mas em formato PDF:
- ✅ Margens: 2cm | 1cm | 1cm | 2cm
- ✅ Não editável (fixo)
- ✅ Pronto para imprimir
- ✅ Fácil de partilhar

### Vantagens do PDF:
- Abre em qualquer dispositivo
- Não precisa Word/LibreOffice
- Tamanho menor
- Formato universal

## 🔧 Detalhes Técnicos

### Bibliotecas Usadas:

1. **docx.js** - Criar documentos Word
   - CDN: unpkg.com/docx@8.5.0
   - Gera .docx nativamente
   - Suporta formatação completa

2. **jsPDF** - Criar documentos PDF
   - CDN: cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1
   - Gera PDF no navegador
   - Suporta texto multilingue

3. **FileSaver.js** - Download de ficheiros
   - CDN: cdnjs.cloudflare.com/ajax/libs/FileSaver.js/2.0.5
   - Facilita download no navegador

### Configuração das Margens:

**DOCX (em inches → convertido para cm):**
```javascript
margin: {
  top: convertInchesToTwip(0.79),    // 2cm
  right: convertInchesToTwip(0.39),  // 1cm
  bottom: convertInchesToTwip(0.39), // 1cm
  left: convertInchesToTwip(0.79)    // 2cm
}
```

**PDF (em milímetros):**
```javascript
const marginLeft = 20;   // 2cm
const marginRight = 10;  // 1cm
const marginTop = 20;    // 2cm
const marginBottom = 10; // 1cm
```

## 📦 Estrutura dos Ficheiros

### Nome do Ficheiro Exportado:
```
Programa_[DATA]_[TITULO-SLUGIFICADO].[extensao]

Exemplos:
- Programa_2024-11-26_i-domingo-do-advento.docx
- Programa_2024-12-25_natal-do-senhor.pdf
- Programa_2025-04-20_domingo-de-pascoa.docx
```

### Conteúdo Incluído:

1. **Cabeçalho:**
   - Nome do coro
   - Título litúrgico
   - Tema extra (se houver)
   - Data formatada

2. **Corpo:**
   - Cada parte do programa
   - Ícone + nome da parte
   - Título do cântico
   - Autor
   - Letra completa
   - Separadores entre partes

3. **Formatação:**
   - Margens corretas
   - Fontes legíveis
   - Espaçamento adequado
   - Quebras de página automáticas (se necessário)

## ⚙️ Configurações de Impressão

### Para DOCX:
1. Abrir ficheiro no Word/LibreOffice
2. **Arquivo → Imprimir**
3. Configurar:
   - Papel: A4
   - Orientação: Retrato
   - Margens: Já definidas (não alterar)
   - Escala: 100%
4. Imprimir

### Para PDF:
1. Abrir ficheiro em leitor PDF
2. **Arquivo → Imprimir**
3. Configurar:
   - Papel: A4
   - Orientação: Retrato
   - Ajustar à página: **NÃO** ❌
   - Tamanho real: **SIM** ✅
   - Escala: 100%
4. Imprimir

## 🐛 Resolução de Problemas

### Problema: Botões não aparecem
**Solução:** 
- Hard refresh (Ctrl+F5)
- Verificar que arquivos foram atualizados

### Problema: DOCX não descarrega
**Solução:**
- Verificar se tem programa preenchido
- Ver consola (F12) para erros
- Tentar PDF em vez de DOCX

### Problema: PDF tem texto cortado
**Solução:**
- Letras muito longas podem quebrar páginas
- Normal e esperado
- Usar DOCX se precisar editar

### Problema: Margens ainda erradas ao imprimir
**Solução:**
- Garantir que não está a usar "Ajustar à página"
- Selecionar "Tamanho real" nas opções
- Verificar driver da impressora

### Problema: Emojis não aparecem
**Solução:**
- Normal em alguns sistemas antigos
- Não afeta funcionalidade
- Ou atualizar sistema/software
